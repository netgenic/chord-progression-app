# Chord Progression App

Интерактивное приложение для поиска, анализа, воспроизведения и дальнейшего экспорта аккордовых прогрессий. Репозиторий находится на этапе bootstrap: до прикладной реализации зафиксированы продуктовые границы, архитектурные решения, проверки качества и ограничения безопасности.

Пользователи закладываются в модель данных и API с самого начала: они смогут владеть создаваемыми данными, добавлять прогрессии в избранное и работать с пользовательскими тегами. Чистое ядро музыкальной теории при этом остаётся независимым от пользователей, HTTP, БД и UI.

## Начало работы

1. Прочитайте [продуктовую спецификацию](docs/product/specification.md).
2. Прочитайте [pre-flight](docs/llm-development/preflight.md) и [текущее состояние](PROJECT_STATE.md).
3. Выполните инструкции из [DEVELOPMENT.md](DEVELOPMENT.md).

Основная проверка после установки зависимостей:

```bash
pnpm verify
```

## Структура

- `apps/web` — будущий браузерный интерфейс;
- `apps/api` — будущий HTTP API и прикладные use cases;
- `packages/music-theory` — чистая каноническая музыкальная модель;
- `packages/database` — будущая схема, миграции и repository adapters;
- `packages/shared` — небольшие действительно общие контракты;
- `packages/ui` — переиспользуемые UI-примитивы после появления потребности;
- `scripts/importers` — проверяемый и идемпотентный импорт источников;
- `docs` — продукт, архитектура, ADR и правила разработки.

Production-код намеренно не добавляется до полного завершения pre-flight.
